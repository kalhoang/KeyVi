- **N2, `THIRD_PARTY_NOTICES.md` does not list the web2 test corpus.** Finding A2: the web2 words are recorded in `data/NOTICES.md` (which `THIRD_PARTY_NOTICES.md` section 2 names as the authoritative list) and in ADR 0200, but `THIRD_PARTY_NOTICES.md` itself has no row for them, while it has rows for the two other corpora that are used in tests only (the prose corpus and the place names). - **N3, the description of the web2 sample cannot be reproduced exactly.** The header of `escape-regression.txt` says the list was "lowercased and deduplicated (210,747 words)". On macOS 27.2 the file has 235,976 entries, 234,456 after lowercasing and removing duplicates; 210,773 entries are written in lowercase in the file, and 210,747 of those are longer than one letter. So the number fits "the lowercase entries, without the single letters", not the wording used, and the script that typed the lists through the engine and took every 15th and every 6th word is not in the repository. ADR 0200 quotes the README's figure (234,936), which is not the size of the file macOS ships either (the BSD maintainers edit the list, as its README says). None of this affects the licence or the membership checks of A2. Suggested: correct the header's wording with the next change to that file (a `corpus-change` in the sense of QA-R6 only if a row changes, which it need not).
- **N4, what the history shows about order.** The range reads as work done in this repository: small commits on named branches, each change built on structures that already existed, a follow-up commit after review (`31fb655f`), fixtures re-recorded with dated reasons. In part B the decision record (`9bba0830`, 16:30) precedes the engine commits (16:38 to 17:12) by commit date, on another branch, and each engine commit carries code, tests, spec amendment and reference model together. The expected outputs of corpus files changed in `3b05dbf4` and `f2968e0a` without a pull request labelled `corpus-change` (QA-R6), because the project merges branches without pull requests at present; the reasons are in `Fixtures/README.txt`.
